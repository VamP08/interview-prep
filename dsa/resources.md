# Resources

Curated, current, all free unless marked. One primary list at a time - finish NeetCode 150 here before adding another sheet.

## Problem lists

| Resource | Size | Best for |
|---|---|---|
| [NeetCode 150](https://neetcode.io/practice/practice/neetcode150) | 150 | THE backbone of this repo; free video solution per problem |
| [NeetCode 250](https://neetcode.io/practice) | 250 | Extra reps per pattern once 150 is done |
| [Blind 75](https://neetcode.io/practice/practice/blind75) | 75 | Compressed refresher before an interview week |
| [Striver A2Z Sheet](https://takeuforward.org/strivers-a2z-dsa-course/strivers-a2z-dsa-course-sheet-2/) | 450+ | Ground-up depth, written editorials; India-MNC oriented |
| [Striver SDE Sheet](https://takeuforward.org/interviews/strivers-sde-sheet-top-coding-interview-problems/) | ~190 | Topic-wise fast track, popular for India product companies |
| [GFG Must-Do](https://www.geeksforgeeks.org/must-do-coding-questions-for-companies-like-amazon-microsoft-adobe/) | ~75 | Company-tagged classics; GFG also has per-company sheets (TCS, Infosys, Wipro) |
| [LeetCode company tags](https://leetcode.com/company/) (premium) | - | Real per-company frequency, last-6-months filter; worth one month before interviews |

## Learning / reference

- [Tech Interview Handbook](https://www.techinterviewhandbook.org/) - end-to-end process guide: resume, study plan, cheatsheets, behavioral
- [AlgoMonster](https://algo.monster/) - pattern flowcharts; the "which pattern when" decision tree is good
- [NeetCode courses](https://neetcode.io/courses) - DSA + advanced algorithms video courses
- [USACO Guide](https://usaco.guide/) - deeper algorithm theory when a notes.md is not enough
- Books: Cracking the Coding Interview (breadth), Elements of Programming Interviews in Python (depth)

## Practice environments and mocks

- [Pramp](https://www.pramp.com/) - free peer mock interviews; do at least a few before real loops
- [interviewing.io](https://interviewing.io/) - anonymous mocks with real engineers (paid, high quality)
- [LeetCode contests](https://leetcode.com/contest/) - weekly timed practice, closest free thing to OA pressure
- [HackerRank](https://www.hackerrank.com/) / [CodeSignal](https://codesignal.com/) - practice IN the platforms OAs actually use; see [online-assessments.md](online-assessments.md)

## Company-specific (India / service + product MNCs)

- [GFG interview experiences](https://www.geeksforgeeks.org/company-interview-corner/) - recent per-company rounds and questions
- [PrepInsta](https://prepinsta.com/) - TCS NQT / Infosys / Wipro / Accenture OA patterns and past questions
- GFG TCS SDE sheet + Infosys coding questions pages - service-company OA staples
